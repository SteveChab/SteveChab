# I set the standards, then build the systems.

Design engineer and accessibility lead in Pittsburgh. Twenty years of design and code, from Carnegie Mellon's 250+ sites to Dell's global storefronts. I'm a Senior Software Engineer at Dell Technologies, where I design and build A/B tests across about six regions.

- **Accessibility standards.** Wrote Carnegie Mellon's web accessibility standards, still published today. At Dell, I lead my team's accessibility practice for experimentation and set its process.
- **Design system.** The CMS templates, authoring tools, and brand standards I architected served more than 250 sites and thousands of staff publishers. I designed and built every cmu.edu homepage redesign over fifteen years, with teams across marketing.
- **XPS relaunch.** Led front-end implementation of Dell's embargoed global relaunch. XPS sold out in two countries and drew Reuters and Ars Technica coverage.
- **AI-augmented workflow.** Close to a dozen engineers use the accessibility-aware agentic workspace I built from my team's code review skills. I also originated a phased initiative that positions experimentation for AI-augmented work.
- **Experience Design Summit.** Co-chaired Dell's global summit: 500+ attendees and 50+ speakers from every region.
- **Patent pending.** Co-invented a media file retrieval method and AI-driven UX workflow with a Dell Distinguished Engineer. Dell filed a U.S. patent application, pending.
